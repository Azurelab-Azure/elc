## 📖 项目简介

电路仿真实验室是一个为电气工程、自动化专业的学生和工程师提供的免费、可靠、易用的电路仿真与教学平台。项目遵循**公益优先、社区驱动、质量至上、知识共享**的核心理念。

## ✨ 主要功能

- 🔌 **电路仿真**：支持三相电、PLC、基础电路、进阶电路等多种类型
- 📊 **示波器**：实时波形显示与分析
- 🎨 **在线绘制**：拖拽式电路图绘制工具
- 📚 **知识库**：丰富的教程、参考资料和FAQ
- 💻 **跨平台**：Web + Electron桌面应用
