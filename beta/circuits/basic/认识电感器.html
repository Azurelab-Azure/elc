电感器：用绝缘导线绕制在磁芯或骨架上形成的线圈，符号 L

原理与符号

电感器（Inductor）是能够将电能转换为磁场能量储存起来的元件，用符号 L 表示。

基本结构：绝缘导线（漆包线）绕制在磁芯（铁氧体、铁粉芯）或空心骨架上。

电路符号：用连续半圆弧表示线圈，分为空心、铁芯、磁芯等类型。

按磁芯分类（考纲要求了解）：

空心线圈 → 电感量小，线性好
磁芯线圈 → 电感量大，体积小
铁芯线圈 → 电感量很大，用于低频
理论考点：识读电路符号，区分不同电感器类型及其命名方法。
电流变化时，线圈自身产生自感电动势，阻碍电流变化

自感现象

自感现象：当线圈中电流发生变化时，线圈自身产生感应电动势，阻碍电流的变化。

eL = − L · Δi / Δt

负号表示自感电动势方向总是阻碍电流变化

经典实验（通电自感）：

闭合开关瞬间，与电感串联的灯泡逐渐变亮，而不是立即变亮。原因是自感电动势阻碍电流增大。

理论考点：理解自感现象，能判断自感电动势方向及对电路的影响。
电感量 L 取决于匝数N、磁导率μ、截面积A和磁路长度l

电感量计算

电感量 L（自感系数）是描述线圈产生自感能力的物理量。

L = N² · μ · A / l

N:匝数 · μ:磁导率 · A:截面积 · l:磁路长度

单位：亨利（H）

1H = 1V·s/A，常用 mH（毫亨）、μH（微亨）。

理论考点：掌握电感量的计算及影响因素（匝数、磁芯材料、尺寸）。
感抗 XL = 2πfL，频率越高、电感越大，阻碍作用越强

感抗与电路特性

感抗 XL：电感对交流电的阻碍作用，单位Ω。

XL = 2πfL = ωL

核心结论：

通直流，阻交流
通低频，阻高频

直流时 f=0 → XL=0 → 电感相当于短路。

理论考点：掌握感抗计算，理解“通直阻交”的原理及应用（扼流圈）。

万用表检测：R×1Ω档测通断，判断开路或短路

检测方法与考纲

理论考点：普通指针式万用表无电感档，只能用电阻档判断好坏。

判断标准（R×1Ω档）：

电阻很小（几Ω） → 正常
电阻∞ → 开路损坏
电阻接近0 → 短路故障

注意事项：

• 每次换档需重新调零

• 匝间短路用电阻法难以判断
